# Snake Web

Juego de Snake multijugador responsivo para navegador web y dispositivos móviles.

---

# Objetivo del Proyecto

Construir una experiencia moderna de Snake en navegador con:

- Multijugador en tiempo real
- Compatibilidad con celular y escritorio
- Sistema de nombres de jugador
- Salas públicas y privadas
- Despliegue en VPS
- Baja latencia mediante WebSockets

---

# Stack Tecnológico

## Frontend
- HTML5
- CSS3

- Canvas API

## Backend (planeado)
- Node.js

- Socket.IO
